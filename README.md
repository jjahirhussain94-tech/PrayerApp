# Salah Tracker

An iPhone app (built with [Capacitor](https://capacitorjs.com)) for tracking your daily prayers. It also runs in a browser.

- **Prayer times for your location.** Calculated on the device with [adhan](https://github.com/batoulapps/adhan-js). Pick your calculation method (MWL, ISNA, Umm al-Qura, Karachi, and more) and the Asr method (standard or Hanafi). Shows a countdown to the next prayer and the Qibla bearing.
- **Prayer log.** Mark each prayer as on time, late, qada, missed or excused (e.g. during menstruation, which doesn't count against you). The app suggests a status from the prayer's time window. For late and qada prayers you can record when you actually prayed. For late or missed prayers you can record why (overslept, work, travel, illness, forgot…) and add a note. You can also note whether you prayed in congregation.
- **Making up missed prayers.** The History tab lists missed prayers you still owe; tap **Made up** once you've prayed one and it's logged as qada.
- **Extra prayers.** Log the 12 sunnah rawatib rak'ahs (2 before Fajr, 4 before and 2 after Dhuhr, 2 after Maghrib, 2 after Isha), plus Duha, Witr and Tahajjud.
- **Reminders (iPhone).** A notification when each prayer time begins, and an optional nudge 15, 30 or 60 minutes before a prayer's time ends if you haven't logged it. Reminders are scheduled on the phone, so they work offline and when the app is closed.
- **Hadith and ayat.** A reminder about prayer on the Today screen and in notifications, chosen to fit how you've been doing. If you've missed a lot, it leads with Allah's mercy and forgiveness (e.g. Qur'an 39:53) alongside the importance of prayer. Owed prayers bring hadith about making them up, illness or travel brings hadith about hardship, a streak brings encouragement to stay consistent, and otherwise it matches the time of day (Fajr, Asr, Isha, the night prayer). All come from the Qur'an, the two Sahihs or Tirmidhi, with references; the English is paraphrased.
- **Surahs recited.** Add the surahs you recited in each prayer. Search by name, meaning or number, with short surahs listed first.
- **History.** See the last 14 days at a glance and go back to any day to fill in or fix entries.
- **Stats.** For 7, 30 or 90 days, or all time: completion rate, on-time rate, current and best streak, congregation rate, prayers still to make up, sunnah rak'ahs per day, prayers per day, a status breakdown for each prayer, the most common reasons for late or missed prayers, how often you offered each extra prayer, and your most recited surahs with a count of ayahs recited.
- **Private.** All data stays on your phone. Use Settings to export or import a JSON backup.

## Running it on your iPhone

You need a Mac with [Xcode](https://apps.apple.com/app/xcode/id497799835) installed, plus Node.js.

1. `npm install`
2. `npm run ios`. This builds the app, copies it into the iOS project and opens it in Xcode.
3. In Xcode, select the **App** target → **Signing & Capabilities** and choose your Apple ID as the **Team**. A free Apple ID works for installing on your own phone. If Xcode says the bundle identifier is taken, change `com.salahtracker.app` to something unique, both there and in `capacitor.config.ts`.
4. Plug in your iPhone, select it at the top of Xcode and press ▶ Run. The first time, go to iPhone **Settings → General → VPN & Device Management** and trust your developer certificate.
   - With a free Apple ID the app stops opening after 7 days; running it from Xcode again renews it. A paid Apple Developer account ($99/year) removes that limit and lets you use TestFlight or publish on the App Store.
5. After changing the web code, run `npm run ios:sync` and press Run again.

No Mac? A cloud build service such as Codemagic or Ionic Appflow can build the iOS app from this repo.

## Development

```bash
npm install
npm run dev      # start the dev server
npm test         # unit tests (stats + prayer time logic)
npm run build    # typecheck and build for production
npm run lint
```

## Structure

- `ios/` – the Xcode project generated by Capacitor
- `src/lib/prayerTimes.ts` – prayer time calculation, prayer windows, suggested status, Qibla
- `src/lib/notifications.ts` – builds and schedules local reminder notifications
- `src/lib/encouragement.ts` – chooses which hadith or ayah fits the user's recent prayers
- `src/data/reminders.ts` – the hadith and ayat, with references
- `src/lib/stats.ts` – statistics over a date range
- `src/lib/storage.ts` – saving data (local storage in the browser, plus iOS Preferences on iPhone) and backup validation
- `src/data/surahs.ts` – all 114 surahs with ayah counts
- `src/components/` – the Today, History, Stats and Settings views
